{%- comment -%} image-zoom.html — click an image in a scheda to open it full screen and zoom up to twice the natural size of the file (200%), with pan. Mouse wheel / trackpad pinch (Safari gesture events too), drag to pan, double-click or double-tap to toggle fit / maximum, two-finger pinch on touch screens, keys + - 0, arrows to pan, Esc to close. Optional: data-zoom-src="/Images/.../file-large.jpg" on an makes the viewer load a larger file than the one shown in the page. The zoom files live on R2: site.zoom_base (https://zoom.medievalvisions.com, set in _config.yml and repeated in _config.production.yml) is prefixed to data-zoom-src here, so the schede keep their root-relative paths. Download button (top right): fetch -> blob -> with the file's own name on the Mac and other desktops; on touch devices (iPhone, iPad) the share sheet (navigator.share with the file), so the image can go to Photos. If the share needs a fresh tap, the button turns into "Save"; if the fetch fails, the file opens in a new tab (or the button becomes an "Open image" link when that tab is blocked). The zoom host sends CORS headers only to the site's origins (R2 bucket CORS rule), and the fetch skips the browser cache, where the left a copy without them. Next to the button: the credit and licence taken from the figcaption ("Photo:", "Image:" or "Source:"). Self-contained: no external libraries, no cookies, no third-party calls. {%- endcomment -%}
