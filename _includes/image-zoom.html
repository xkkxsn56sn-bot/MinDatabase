{%- comment -%} image-zoom.html — click an image in a scheda to open it full screen and zoom up to twice the natural size of the file (200%), with pan. Mouse wheel / trackpad pinch (Safari gesture events too), drag to pan, double-click or double-tap to toggle fit / maximum, two-finger pinch on touch screens, keys + - 0, arrows to pan, Esc to close. Optional: data-zoom-src="/Images/.../file-large.jpg" on an makes the viewer load a larger file than the one shown in the page. The zoom files live on R2: site.zoom_base (empty locally, https://zoom.medievalvisions.com in production, see _config.production.yml) is prefixed to data-zoom-src here, so the schede keep their root-relative paths. Self-contained: no external libraries, no cookies, no third-party calls. {%- endcomment -%}
